# homebrew-vlt

Official Homebrew Tap for [`vlt`](https://github.com/raynosc/vlt) — A production-grade, local-first, zero-knowledge secrets and password manager.

## Installation

### GUI Desktop Application (macOS)
Installs `vlt.app` into `/Applications` without Gatekeeper warnings:

```bash
brew install --cask raynosc/vlt/vlt
```

### CLI, TUI, Quick Access & Sync Server (macOS & Linux)
Installs `vlt`, `vlt-tui`, `vlt-quick`, and `vlt-sync` into your PATH:

```bash
brew install raynosc/vlt/vlt
```

## Updates

```bash
brew update
brew upgrade vlt
```
